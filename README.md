# Car Price Prediction using Machine Learning

## About the Project

This project focuses on predicting the selling price of used cars using machine learning regression techniques.

The project includes data preprocessing, exploratory data analysis, feature analysis, categorical encoding, model training, and performance comparison.

## Dataset

The dataset contains information about used Audi cars, including:

- Model
- Year
- Price
- Transmission
- Mileage
- Fuel Type
- Tax
- MPG
- Engine Size

After removing duplicate records, the dataset contains **10,565 records**.

## Project Workflow

1. Data Loading
2. Data Exploration
3. Data Preprocessing
4. Duplicate Removal
5. Exploratory Data Analysis
6. Feature and Target Separation
7. Categorical Feature Encoding
8. Train-Test Split
9. Model Training
10. Model Evaluation
11. Model Comparison
12. Price Prediction

## Machine Learning Models

The project uses regression models to predict car prices, including:

- Linear Regression
- Random Forest Regressor

## Results

The Random Forest Regressor achieved the best performance with:

- **R² Score:** 0.9569
- **MAE:** 1559.12
- **RMSE:** 2468.97
